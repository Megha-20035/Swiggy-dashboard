# Swiggy Sales & Customer Insights Dashboard

## Overview

This project is an interactive Power BI dashboard created to analyze Swiggy sales performance, customer behavior, restaurant trends, and delivery insights. The dashboard helps in understanding key business metrics through dynamic visualizations and KPI tracking.

## Project Objectives

* Analyze overall sales and revenue trends
* Track customer ordering behavior
* Monitor restaurant performance
* Evaluate delivery efficiency
* Identify top-performing categories and locations
* Create interactive filters for better business analysis

## Tools & Technologies

* Power BI
* SQL
* Excel / CSV Dataset
* Data Cleaning & Transformation
* DAX Measures

## Dashboard Features

* Revenue & Order KPI Cards
* Sales Trend Analysis
* Customer Insights
* Restaurant Performance Tracking
* Delivery Analysis
* Interactive Slicers & Filters
* Category-wise Performance
* Region-wise Order Distribution

## Key Insights

* Identified peak order periods and high-performing categories
* Analyzed customer purchasing patterns
* Compared restaurant ratings and delivery performance
* Tracked revenue contribution across multiple segments

## Skills Demonstrated

* Data Visualization
* Data Cleaning
* Data Modeling
* DAX Calculations
* Business Intelligence
* Dashboard Design
* Analytical Thinking


## Conclusion

This dashboard provides meaningful business insights that can help improve operational efficiency, customer experience, and overall sales performance.
